## 玩法

1. **书卷之路**：首页展示 66 卷路线图，全部开放，点任意一卷即可进入闯关。
2. **闯关地图**：每卷分 10 关（每关约 5 章、60 题），全部关卡已解锁，自由挑战。
3. **答题闯关**：每题 4 个选项，答完立即显示答案、经文与解析；每关**随机抽 20 题**，可用 **🧭 跳题** 跳到任意题；答对 12 题即过关。
4. **星星奖励**：答对 12 题 = ⭐1，15 题 = ⭐⭐，18 题 = ⭐⭐⭐；进度自动保存在本机浏览器。
5. **漫画动画**：每关开头有一幅手绘风 SVG 漫画（太阳转动、波浪、彩虹、骆驼、天梯……全都有动画）。
6. **内容音频**：点击 🔊 可朗读题目、经文、解析；答对答错有过关音效，设置里可调语速、换声音、关音效。

## 如何添加下一卷（例如《出埃及记》）

1. 在 `data/books.js` 中找到 `EXO`，把 `available` 改为 `true`。
2. 新建 `data/exodus.js`，格式与 `genesis.js` 完全一致：

```js
window.BIBLE_QUIZZES = window.BIBLE_QUIZZES || {};
window.BIBLE_QUIZZES.EXO = {
  "1": {                              // 第 1 关
    title: "摩西出生",                 // 关卡名
    range: "出埃及记 1–4章",           // 经文范围
    scene: "creation",                // 漫画场景（可选，默认复用）
    desc: "……",                       // 关卡介绍
    questions: [                      // 20 题
      { q: "……",                       // 谜语/题目
        options: ["A","B","C","D"],    // 四个选项
        answer: 0,                     // 正确答案下标（0=A）
        ref: "出埃及记 1:1",           // 经文出处
        verse: "「……」",               // 经文原文
        explain: "……" }               // 解析
    ]
  }
  // ……共 10 关，每关 20 题
};
```

3. 在 `index.html` 的 `<script src="data/genesis.js"></script>` 后面加一行 `<script src="data/exodus.js"></script>`。
4. 打开页面即可在书卷之路上看到《出埃及记》开放。

> 提示：给新卷的每关配上专属漫画场景会更生动——在 `index.html` 的 `comicSVG()` 里加一个场景函数即可。
